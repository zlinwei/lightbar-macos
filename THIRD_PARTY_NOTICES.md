## Serial module documentation

The DevEBox nRF24L01 wireless serial module manuals (1904M/1908M) supplied the AT command format, default UART settings and framing constraints. The vendor PDFs, drivers and firmware are not distributed with this repository, and no license to those materials is granted here.

Apple SDKs and system tools are supplied separately by Apple. SF Symbols are rendered through the system APIs, not redistributed as a third-party icon package. The application icon is generated by the project's original drawing script.

Product names identify compatible hardware; this is an independent project without vendor endorsement.
